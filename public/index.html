Download & installation help

How do I install on iPhone or iPad?

Open Project Sora in Safari, tap Share, choose Add to Home Screen, then confirm.

How do I install on Android?

Open Project Sora in Chrome, tap the browser menu, then choose Install app or Add to Home screen.

How do I install on Windows or Mac?

Open Project Sora in Chrome or Edge. Use the install icon in the address bar, or open the browser menu and choose Install Project Sora.

The install option is missing—what should I try?

Use Safari on iOS or Chrome/Edge on Android and desktop, confirm the site finished loading, and avoid private browsing. You can still use Project Sora normally without installing it.

What should I include in a bug report?

Include what you expected, what happened, the device/browser, the page or feature, and clear steps that reproduce the issue. Do not include passwords or API keys.
